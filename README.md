# 🔐 Web Terminal — Secure Mobile Terminal + tmux Manager

**English** | [فارسی](#-ترمینال-وب--نسخه-امن)

---

## English

Most web-based terminal environments today have weak security. A simple bot can gain shell access within seconds.

**This project is different.** Those insecure defaults are gone, and the terminal is built with security in mind from the start.

### ✨ Highlights

- 🛡️ Designed to avoid the common weaknesses of web terminals
- 📱 Mobile-friendly terminal in your browser
- 🧩 tmux session manager built in
- ⚡ One-command install, self-contained script

### 🚀 Quick Install

```bash
curl -fsSL https://raw.githubusercontent.com/configfars-TM/Web-Terminal/refs/heads/main/terminal-tmux-manager.sh | bash
```

> 💡 **Tip:** If you prefer to review the script before running it, download it first:
>
> ```bash
> curl -fsSL -o terminal-tmux-manager.sh https://raw.githubusercontent.com/configfars-TM/Web-Terminal/refs/heads/main/terminal-tmux-manager.sh
> less terminal-tmux-manager.sh
> bash terminal-tmux-manager.sh
> ```

### 📋 Requirements

- A Linux system
- `bash` and `curl`
- Internet access during installation
